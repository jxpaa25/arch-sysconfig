# Keybindings

Every bind on the current Omarchy setup, and what happens to it on the new system. Generated by
comparing against the live list, so nothing is missing.

- **keep**: works as it does now, using Hyprland itself or a package already on the list.
- **port**: same key and behaviour, but it needs a small script of ours or a Quickshell feature.
- **drop**: goes away.

Totals: 127 keep, 70 port, 44 drop. Lid-switch handling has no label so it isn't counted here. It gets ported as a script.
